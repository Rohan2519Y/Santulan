## Global rules for every task (from the constitution)

- **Principle III**: nothing beyond BUILD 01 — no extra table, column, index, enum value, trigger, function or role — without a change record and the user's approval. Any value the contract does not state is marked `-- ASSUMED (D-11)` in the migration.
- **Never edit an applied migration**; a fix is a new numbered file. All migrations are forward-only.
- No PII columns; no client-supplied scores/versions/IDs; no runtime role with `BYPASSRLS`; no prohibited claims in any UI string.
- Concurrency tests use **separate connections** and clean up explicitly (a single rolled-back connection cannot prove advisory-lock behaviour).
- Record staging-only checks as `NOT_EXECUTED` in the evidence register; never mark them PASS.
